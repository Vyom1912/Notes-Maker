# 📝 PatelKeeps — Google Keep Clone

A note-taking app inspired by **Google Keep**. Create, edit, search and delete notes. Everything saves automatically in your browser, so your notes are still there when you come back.

## ✨ Features

- **Create** a note with one click; it opens ready to type
- **Edit** by clicking a note or the edit button; press **Esc** or **Ctrl + Enter** to finish
- **Autosave** while you type, with a "last edited" timestamp on each note
- **Search** notes as you type
- **Delete** notes with a smooth exit animation
- Notes saved to **localStorage** and kept across page reloads
- **Smooth animations**: cards pop in, lift on hover and fade between view and edit mode
- **Responsive grid**: several columns on desktop, one column on phones
- Empty-state messages when there are no notes or no search results
- Respects the system **reduced-motion** setting

## 🛠️ Built With

- HTML5
- CSS3 (Grid, keyframe animations, media queries)
- JavaScript (Vanilla, localStorage)
- [Font Awesome](https://fontawesome.com/)
